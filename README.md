# WJCT_plugin
Test plugin for WJCT

This plugin will generate the custom post type CatPicks along with methods to create and save meta data functionality. 
All with in one php class for code cleanliness. 

How to install - Login to WP admin, navigate to Plugins and click Activate undere 'Cat Picks'

How to test - Create a new post under the newly created custom post type and click Publish ands view on
the front end too see it work under the new child theme's single CPT template also.
